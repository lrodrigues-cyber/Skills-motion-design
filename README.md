# Skills motion design

Un skill Claude par style de motion design (une forme de montage pour un type de produit).

| Skill | Style | Références |
|---|---|---|
| [`dashboard-cinematique`](dashboard-cinematique/SKILL.md) | Interface SaaS sombre filmée en macro sur un plan 3D incliné, profondeur de champ courte, néons lumineux, plans de 3 s, recul + logo tracé, musique électronique sombre et design sonore calé à l'image | 5 vidéos analysées plan par plan, image et son ([analyse](dashboard-cinematique/references/analyse-references.md)) |

## Structure d'un skill

```
<skill>/
├── SKILL.md              recette du style + workflow (lu par Claude)
├── references/           analyse des vidéos de référence, recettes détaillées
├── scripts/              création d'un projet
└── assets/template/      projet Remotion prêt à rendre (composants, film d'exemple, générateur de son)
```
